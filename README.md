# Vítej na LuigiSMP! 👋

LuigiSMP je **forever world**: server, co se nikdy neresetuje, vyvíjený jedním člověkem s láskou k detailu. Kromě klasického přežívání tu najdeš spoustu vlastních systémů: claimy na ochranu stavby, ekonomiku, ochočitelná zvířata, vlastní itemy a hlubinný gamemode Rock Bottom.

Nic nemusíš stahovat ani instalovat, stačí se připojit a hrát.
