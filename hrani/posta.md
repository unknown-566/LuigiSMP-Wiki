# Pošta

```
/mail
```
(nebo `/posta`)

Krátké menu se zprávami, které ti server pošle za různé odměny a milníky (třeba za [Rock Bottom](../rock-bottom/zaklady.md)). Otevřeš, klikneš na zprávu, vyzvedneš odměnu, hotovo.

Zprávy se nemažou, takže není kam spěchat. Hráči si mezi sebou poštu posílat nemůžou, je jen systémová.

Některé odměny jdou vyzvednout jen na určitém místě (třeba jen na SMP mapě), pokud to tak je, uvidíš to napsané přímo u zprávy.
