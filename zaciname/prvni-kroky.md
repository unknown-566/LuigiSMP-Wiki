# První kroky

## 1. Výběr jazyka

Při prvním připojení tě server hned zeptá, jestli chceš hrát v **češtině** nebo **angličtině**. Vyber si a hra tě krátce odpojí, aby se jazyk aplikoval. Prostě se připoj znovu.

Jazyk můžeš kdykoliv později změnit příkazem:
```
/lang cz
/lang en
```
(nebo jen `/lang` pro nabídku)

Skoro všechny hlášky na serveru (claimy, pošta, mining...) respektují tenhle výběr.

## 2. Pravidla serveru

Při prvním připojení se ti ukáže **Code of Conduct**, vanilkový obrazovka s pravidly, kterou musíš potvrdit, než vstoupíš do světa.

## 3. Info o serveru

Po pravidlech a výběru jazyka dostaneš krátký dialog o tom, co server je. Vyvíjí ho jeden člověk, je to forever world (žádné resety), a najdeš tu custom itemy, co působí jako módy, i když běží na čisté vanille.

## 4. Propoj si Discord

Pokud jsi na našem Discordu, propoj si účet příkazem:
```
/link
```
Propojení se ti připomene i přímo v dialogu s jazykem, pokud ještě nejsi propojený. Proč se to vyplatí? Podívej se na [Odměny za aktivitu](../odmeny/aktivita.md): čím víc píšeš na Discordu, tím lepší výhody na serveru dostáváš (víc domovů, víc claimů...).

## 5. Co dál?

* Nastav si první domov → [Domovy](../postava/domovy.md)
* Zkus si ochránit pozemek → [Claimy](../claimy/claimy.md)
* Zajdi se podívat do hlavního gamemode → [Rock Bottom](../rock-bottom/zaklady.md)

## Užitečné základní příkazy

| Příkaz | Co dělá |
|---|---|
| `/spawn` | Teleport na spawn |
| `/nastaveni` | Osobní nastavení (zvuky, notifikace, nameplate...) |
| `/playtime` | Kolik jsi toho odehrál/a |
| `/map` | Odkaz na online mapu serveru |
| `/web` | Odkaz na web serveru |
