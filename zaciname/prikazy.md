# Seznam příkazů

Všechny příkazy SMP na jednom místě. Skoro všechno z toho najdeš i jako tlačítko v [`/profil`](../hrani/profil.md). Příkazy dolu jsou na stránce [Rock Bottom, seznam příkazů](../rock-bottom/prikazy.md).

## Základ

| Příkaz | Co dělá |
|---|---|
| `/profil` | Menu se vším, co jde na SMP dělat |
| `/lang` | Jazyk (čeština / angličtina) |
| `/nastaveni` | [Osobní nastavení](nastaveni.md) |
| `/link` | Propojení s Discordem, viz [Odměny za aktivitu](odmeny-za-aktivitu.md) |
| `/mail` | [Pošta](../hrani/posta.md) |
| `/playtime`, `/pttop` | Odehraný čas a žebříček |
| `/web` | Odkaz na web serveru |

## Cestování

Podrobnosti: [Domovy a cestování](../hrani/domovy-a-cestovani.md).

| Příkaz | Co dělá |
|---|---|
| `/sethome [název]`, `/home [název]`, `/homes`, `/delhome [název]` | Domovy |
| `/tpa <hráč>`, `/tpahere <hráč>`, `/tpaccept`, `/tpdeny` | Teleport k hráči |
| `/rtp` | Náhodný teleport |
| `/spawn` | Teleport na spawn |
| `/back` | Zpět na místo smrti ($300) |
| `/warp [název]`, `/delwarp <název>` | [Veřejné warpy](../ekonomika/za-co-utracet.md) |
| `/afk` | Režim pryč od klávesnice |

## Claimy

Podrobnosti: [Claimy](../hrani/claimy.md).

| Příkaz | Co dělá |
|---|---|
| `/claim`, `/claim create <název>` | Založí claim nebo rozšíří sousední |
| `/claim addchunk`, `/claim delchunk` | Přidá nebo odebere chunk |
| `/claim list`, `/claim see` | Seznam claimů, zobrazení hranic |
| `/claim trust <hráč>`, `/claim untrust <hráč>` | Přístup pro kamarády |
| `/claim settings` | Co smí trusted hráči a ostatní |
| `/claim rename`, `/claim transfer`, `/claim unclaim` | Správa claimu |
| `/claim fly` | Létání v claimu |
| `/claim tp`, `/claim setspawn` | Teleport do claimu (jen VIP) |

## Peníze

Podrobnosti: [Jak vydělat](../ekonomika/jak-vydelat.md).

| Příkaz | Co dělá |
|---|---|
| `/balance [hráč]`, `/balancetop` | Zůstatek a žebříček |
| `/send <hráč> <částka>` | Pošle peníze hráči |
| `/ukoly` | Denní úkoly |
| `/vykup`, `/value` | Výkup věcí a cena itemu v ruce |
